# Client Setup

## 1. Get the client

Download the client build matching this project (see [Azeroth Universe Download](https://github.com/AzerothUniverseCore/UniverseEmu/releases/tag/UniverseData) for the correct version/patch).

> ⚠️ *Aurora — fill in the exact client download link/instructions here (self-hosted download, torrent, etc.), whichever you're currently pointing players to on the site/Discord.*

## 2. Point the client to your server

Edit `WTF\realmlist.wtf` in your client folder and set it to your server's address:

```
set realmlist 127.0.0.1
```

Replace `127.0.0.1` with your server's LAN/public IP if you're not testing locally.

## 3. Launch and log in

Start the client, log in with the account you created in [Server Setup](server-setup), and create a character.
