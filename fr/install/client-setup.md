# Configuration du client

## 1. Récupérer le client

Télécharge le client correspondant au projet (voir [Azeroth Universe Download](https://github.com/AzerothUniverseCore/UniverseEmu/releases/tag/UniverseData) pour la bonne version/patch).

> ⚠️ *Aurora — complète ici le lien/les instructions exactes de téléchargement du client (hébergement perso, torrent, etc.), celles que tu utilises actuellement sur le site/Discord.*

## 2. Pointer le client vers ton serveur

Édite `WTF\realmlist.wtf` dans ton dossier client et renseigne l'adresse de ton serveur :

```
set realmlist 127.0.0.1
```

Remplace `127.0.0.1` par l'IP LAN/publique de ton serveur si tu ne testes pas en local.

## 3. Lancer et se connecter

Lance le client, connecte-toi avec le compte créé lors de la [configuration du serveur](server-setup), et crée un personnage.
