Qu'est-ce qu'AzerothUniverseCore / UniverseEmu ?

UniverseEmu est un framework de serveur basé sur TrinityCore (3.3.5a) qui fait tourner le projet Azeroth Universe. Il apporte du contenu et des systèmes issus de Cataclysm et de Mists of Pandaria sur un client WotLK 3.3.5a, ainsi qu'un grand nombre de systèmes personnalisés.

Logiciels requis

  • Git Extensions ≥ 2.51.2
  • MS Visual Studio Community ≥ 17.0 (2022)
  • MariaDB ≥ 10.5.8
  • Boost ≥ 1.78

⚠️ N'oublie pas de renseigner le mot de passe root MariaDB défini à l'installation — tu en auras besoin pour configurer worldserver.conf.

Exemple de configuration

LoginDatabaseInfo     = "127.0.0.1;3306;root;TON_MOT_DE_PASSE;auth"
WorldDatabaseInfo     = "127.0.0.1;3306;root;TON_MOT_DE_PASSE;world"
CharacterDatabaseInfo = "127.0.0.1;3306;root;TON_MOT_DE_PASSE;characters"
